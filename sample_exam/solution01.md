# Aufgabe 1 (18)

- Eine Variable kann nach ihrer Initialisierung erneut einen anderen Wert zugewiesen bekommen. Eine Konstante hingegen wird einmalig initialisiert und kann danach nicht mehr verändert werden (Schlüsselwort **final**) (2).

- Bei einer kopfgesteuerten Schleife (**while**) wird die Bedingung _vor_ dem ersten Durchlauf geprüft – der Schleifenkörper wird daher möglicherweise kein einziges Mal ausgeführt. Bei einer fußgesteuerten Schleife (**do-while**) wird die Bedingung _nach_ dem ersten Durchlauf geprüft – der Schleifenkörper wird daher mindestens einmal ausgeführt (4).

- Primitive Datentypen (z. B. **int**, **double**, **boolean**) speichern den Wert direkt. Referenzdatentypen (z. B. Klassen, Arrays) speichern eine Referenz (Speicheradresse) auf das eigentliche Objekt im Heap (2).

- Die 4 Grundprinzipien der objektorientierten Programmierung sind:
  - **Abstraktion**: Komplexe Systeme werden auf ihre wesentlichen Eigenschaften und Verhaltensweisen reduziert; unwichtige Details werden ausgeblendet (2).
  - **Kapselung**: Daten und Methoden werden in einer Klasse zusammengefasst. Der direkte Zugriff von außen wird durch Zugriffsmodifikatoren (z. B. **private**) eingeschränkt; der Zugriff erfolgt über definierte Schnittstellen (Getter/Setter) (2).
  - **Vererbung**: Eine Klasse (Unterklasse) kann Attribute und Methoden einer anderen Klasse (Oberklasse) übernehmen und erweitern. Dies fördert die Wiederverwendung von Code (2).
  - **Polymorphismus**: Objekte unterschiedlicher Unterklassen können über eine gemeinsame Oberklassen-Referenz angesprochen werden. Methoden können je nach tatsächlichem Objekttyp unterschiedlich ausgeführt werden (2).

- Eine Klasse ist ein Bauplan, der Attribute und Methoden definiert. Ein Objekt ist eine konkrete Instanz dieser Klasse, die zur Laufzeit im Speicher angelegt wird und eigene Attributwerte besitzt (2).
